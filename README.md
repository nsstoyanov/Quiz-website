# 🎯 Quiz Web Application

An interactive web-based quiz platform inspired by Kahoot.  
Users can create, manage, and solve quizzes while tracking their results.

---

## 🚀 Features

- User registration and login
- View all available quizzes
- Create and edit quizzes
- Add, edit, and delete questions
- Solve quizzes individually
- View quiz results and final score

---

## ❓ Question Types

- **Single Choice** – 4 options, 1 correct answer  
- **Multiple Choice** – 4 options, multiple correct answers  
- **True / False** – 2 options, 1 correct answer  

---

## 💾 Data Storage

- LocalStorage or external database (e.g., Firebase)

---

## 🛠 Validation

- Unique username check  
- Email and password validation  
- Proper answer validation per question type  

---

## 🖥 Pages Included

- Login / Register  
- Quiz List  
- Create / Edit Quiz  
- Solve Quiz  
- Results Page
